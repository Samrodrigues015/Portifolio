Portfolio

Este é um site simples e responsivo, desenvolvido em HTML, CSS e JavaScript, criado para apresentar um portfólio pessoal de forma clara e objetiva.

Tecnologias Utilizadas

HTML5 – Estrutura do site

CSS3 – Estilização e responsividade

JavaScript (ES6) – Interatividade e funcionalidades dinâmicas

Estrutura do Projeto
portfolio/
│── assets/             # Arquivos estáticos
│   ├── css/            # Arquivos de estilo
│   ├── js/             # Scripts em JavaScript
│   └── img/            # Imagens utilizadas no site
│
│── index.html          # Página inicial
│── about.html          # Página "Sobre"
│── projects.html       # Página "Projetos"
│── contact.html        # Página "Contato"

Como Rodar o Projeto

Baixe ou clone este repositório:

git clone https://github.com/Samrodrigues015/Portifolio.git


Abra o arquivo index.html diretamente no navegador
ou utilize uma extensão de servidor local como Live Server no VS Code.

Funcionalidades

Layout moderno e responsivo

Estrutura simples e fácil de editar

Páginas separadas para Sobre, Projetos e Contato
